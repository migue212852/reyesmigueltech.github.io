# Investigación: salud computacional

Espacio para proyectos vinculados a análisis de datos de salud, estadística, modelización y herramientas computacionales.

## Organización sugerida de futuros proyectos

- `proyecto_x/README.md`: pregunta de investigación, método, autoría y referencias.
- `proyecto_x/notebooks/`: experimentos reproducibles.
- `proyecto_x/src/`: funciones y scripts.
- `proyecto_x/results/`: figuras y reportes aptos para difusión.

**Privacidad:** no subir historias clínicas, imágenes identificables, datos personales de pacientes ni información sujeta a confidencialidad. Emplear datos públicos, sintéticos o previamente anonimizados y habilitados para difusión.
